# Ad Variation Framework

A structured approach to testing and iterating on ad creatives by systematically varying specific elements while maintaining a consistent core framework.

## Core Principles

The most effective ad variation strategy isn't about constant reinvention. It's about isolating and testing the key drivers of performance. The best variations focus on six core areas: new hooks, new subtitles, different video lengths, different call to actions, different voiceovers, and changes to the underlying ad framework.

This framework is designed for speed and clarity in learning. By keeping the structure stable, you can isolate what actually moves the needle. The goal isn't random experimentation but precision in testing. You're not guessing; you're measuring.

## Variation vs. Framework

There's a natural tension between innovation and consistency. Changing the entire ad framework can unlock new engagement patterns, but it also makes performance comparisons messy. The smarter path is to keep the core structure fixed while rotating in different creative elements like hooks, subtitles, or CTAs.

This balance lets you test bold ideas without losing signal. Running six different ad angles in parallel within a single campaign allows Meta's algorithm to optimize for performance and automatically eliminate underperforming variants. This setup works best when you're testing distinct creative directions but keeping the underlying structure consistent across all variations.

## Practical Execution

You don't need to rebuild an entire ad to test something new. A single day of testing can include three new hooks, three new subtitles, and three different video lengths. This focused iteration lets you isolate what works without losing the signal from a consistent structure.

A five-image, two-primary-text, two-headline Dynamic Creative setup allows for testing multiple hook variations while maintaining a consistent format and control baseline. Clone settings from the control ad set to ensure fair comparison. This setup enables systematic testing of creative elements at scale without sacrificing stability.

This framework is being used to improve performance beyond the current ~$10 per lead cost in the client's Meta ad campaign. By shipping six ads over six days, each with a different angle but within one campaign, the algorithm can identify winners and scale them efficiently.
