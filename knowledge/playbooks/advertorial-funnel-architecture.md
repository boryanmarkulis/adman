# Advertorial Funnel Architecture

## Start From A Working Page
Do not start from a blank page if you can avoid it. Find a working advertorial in the same niche, or a close niche, and break it down.

Look at:
- The headline
- The opening story beat
- Where the product appears
- How the CTAs are phrased
- What proof shows up and when
- Whether the page is doing the selling or just warming the click

Write the brief from what is already working, then build your version from that skeleton.

## Make It Native
The page should feel like it belongs in the feed or inbox it came from.

Use the frame that fits the audience:
- Newspaper-style for older readers who trust article format
- Native news or listicle style for social traffic
- A story-first frame when the product needs desire built before the ask

The point is not to look clever. The point is to lower resistance, the same discipline behind [[ecommerce-landing-page-structure]].

## Choose The Right Path
Use the simplest path that preserves conversion.

- If the story is doing the selling, send them to a sales page first, then checkout
- If the product page already converts, test advertorial to product page first
- If the page is basically the sales page, do not add another step just to feel strategic
- When the funnel is weak, remove steps before you add more

Story builds desire. Sales page sells. Checkout closes.

## Raise AOV On Purpose
A funnel is worth more than a checkout if the math supports it.

Use:
- Bundle pages
- Post-purchase upsells
- Downsell offers
- Buy-more-save-more framing

If you hide the price at the top, make sure the story is doing real work. People need to feel the value before they commit.

When you show bundle pricing, include the unit price too. That makes the offer feel real instead of foggy.

## Track Every Step
Instrument the funnel as a stack of events, not a vague blob.

Track:
- Page view
- Add to cart
- Initiate checkout
- Purchase
- Upsell acceptance

Track value at each step. If you do not know where money is leaking, you are guessing.

Use clean naming so you can read the data later without getting lost in the noise, the same structure [[offer-architecture-and-mapping]] maps out.
