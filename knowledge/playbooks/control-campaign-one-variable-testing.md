# Control Campaign and One-Variable Testing

## Start With A Control
Pick the ad, offer, or funnel version that already works and treat it as the baseline. The goal is not to reinvent everything. The goal is to know what is actually paying you.

## Change One Thing
If you want to test, change one variable at a time.

- One hook
- One creative format
- One offer angle
- One landing page section
- One email subject line

If you change too many things at once, you do not learn anything useful.

## Watch The Control
A control that has been stable for months can still break when the environment shifts. Rising CPA, red days, stock problems, or seasonality are signals to stop guessing and inspect the system.

If the control falls below break even, switch from growth mode to diagnosis mode, the same signal [[green-means-scale-red-means-no]] is built on.

## Rebuild Fast
When the problem is obvious, move quickly:
- Reduce spend
- Re-test fresh creative
- Improve the offer
- Increase LTV
- Use organic traffic to lower blended CPA

The point is to recover signal, not to argue with the market, the same restraint behind [[media-buying-is-not-the-lever]].
