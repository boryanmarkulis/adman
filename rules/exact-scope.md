# Read the scope exactly

## Rule

A rejection of one angle is not a rejection of the offer. A retraction of one element is not a retraction of the instruction. An edit to a named section is an edit to that section only.

Interpret every signal at its precise semantic scope.

## Why

Over-reading a "no" has killed live work that was only being adjusted. Under-reading it has shipped things that were already declined.

## Apply

When a correction arrives mid-task, restate what you understood to be withdrawn before acting on it. One line. Then proceed.
