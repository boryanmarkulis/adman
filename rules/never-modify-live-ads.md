# Never modify live ads

## Rule

Treat every active ad, ad set, and campaign as read-only.

- Read-only inspection is fine and encouraged.
- Never edit, publish, pause, reactivate, duplicate, or make an API mutation against a live object.
- "Go for it" is not authorization to touch live advertising.
- Only act when the exact object and the exact change are both named, and the person has been told it can disrupt delivery.
- Proposed changes ship as a separate paused draft.

## Why

A change that looks narrow, like a single event setting, can trigger re-review, re-learning, or a pause across an entire account. Learning phase is expensive and non-refundable.

## Apply

Draft, show, wait for a named go. Adding a new paused ad set to an existing live campaign is not modification and is allowed. Inventing a new campaign when one already exists is not.
