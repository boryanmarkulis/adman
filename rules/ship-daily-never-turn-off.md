# Ship new creative every day, and never turn an ad off

## Rule

Ship three new ad sets per account every day, one per track, by default. Never zero. Never pause a live ad, and never suggest pausing, thinning the field, consolidating ad sets, or freeing budget. Never hold back a round waiting for "learnings" or statistical significance.

## Why

Creative is the lever and volume is the strategy. Low-cost ads depend on higher-cost ads feeding the funnel, so killing the top starves the bottom. The platform's allocation of spend is itself the measurement: a new ad set that takes little budget is a reading, not a problem. Rules like "avoid constant creation" came from accounts where creative was expensive to make. When creative is cheap to produce, more shots on goal wins.

This rule forbids the suggestion, not only the action. An agent that keeps proposing pause lists wastes the operator's attention every morning.

## Apply

- Run `/ad-loop` daily. Three tracks (A small swings on the control, B develop account signals, C new angle from outside), all shipped.
- Report low spend on a new ad set as an observation. Never as a defect, a blocker, or a reason to skip.
- Never write that new ads are "starving". If it is good it will win spend.
- Any page in `knowledge/` that says otherwise is superseded for this loop.
