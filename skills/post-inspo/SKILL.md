# Post Inspiration

Research what is earning unusual attention now. Do not confuse a popular account with an unusually strong post.

## Process

1. Read `SUBJECT.md`, `VOICE.md`, and the newest report in `research/inspo/` if it exists.
2. Search the current market, competitors, customer language, news cycle, and platform formats. Use the host web tools. Use `scripts/exa.py` only when `EXA_API_KEY` is configured.
3. Prefer posts with observable engagement relative to the account's normal baseline. Mark weak evidence plainly.
4. Rank six to eight formats. For each, capture the source link, observed signal, hook, emotional driver, and a client-specific adaptation.
5. Reject anything that depends on a false claim, copied branding, or an unavailable asset.
6. Save the dated report to `research/inspo/YYYY-MM-DD.md`, creating the folder when needed.

End with the three strongest ideas for the next content batch. This skill researches and recommends. It does not publish.
