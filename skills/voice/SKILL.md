# Voice

Use this before returning ads, posts, emails, scripts, landing-page copy, or replies.

## Process

1. Read `VOICE.md` and `SUBJECT.md` from the repository root.
2. Identify the channel, audience, desired action, and stakes.
3. Use the matching channel profile and verbatim examples in `VOICE.md`.
4. If the relevant profile still contains `TODO`, say the voice is incomplete. Continue with the standing rules unless the operator wants to fill it first.
5. Draft, then run `skills/copywriting/references/read-aloud-pass.md`.
6. Check for invented claims, emojis, em dashes, filler openers, corporate jargon, and generic AI phrasing.

Return the finished draft with one short line naming the channel and any missing voice context. Never publish from this skill.
